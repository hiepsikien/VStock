# VStock brand marks (lime)

## Color tokens

| Token | Hex | Use |
|-------|-----|-----|
| lime | `#C8F000` | Squircle fill, primary accent |
| ink | `#0A0A0A` | Chart arrow; wordmark on light |
| paper | `#F4F4F0` | Wordmark on dark |
| void | `#0A0A0A` | Dark lockup background |

## Source SVGs

| File | Purpose |
|------|---------|
| `vstock-mark.svg` | Flat master mark (no glow) |
| `vstock-icon-app.svg` | App icon source (1024²) |
| `vstock-lockup.svg` | Horizontal lockup on dark |
| `vstock-lockup-transparent.svg` | Lockup without background |
| `vstock-lockup-on-light.svg` | Lockup for light surfaces |

## Raster exports

| File | Purpose |
|------|---------|
| `mark.png` | Mark 1024² |
| `logo-with-name.png` | Dark lockup |
| `logo-with-name-transparent.png` | Transparent lockup |
| `splash-logo.png` | Mark centered on void |

## Rules

- Master assets are **flat** — no outer glow (glow only in marketing/splash comps).
- Prefer SVG; rasterize at 1×/2×/3× as needed.
- Keep chart arrow ink on lime for the mark.
- Wordmark paths are outlined (Inter Bold, tight tracking).
